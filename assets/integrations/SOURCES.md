These small identity marks appear next to installation instructions only. Their use indicates compatibility, not sponsorship or endorsement. Trademarks remain with their respective owners. Icon shapes are not part of Design Engineering's own logo.

- `claude.svg`: Claude mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/master/icons/claude.svg); shape preserved, terracotta fill for GitHub theme contrast.
- `codex.svg`: Codex mark from [theSVG](https://github.com/glincker/thesvg/blob/main/public/icons/codex/default.svg); shape preserved, indigo fill for GitHub theme contrast.
- `../design-engineering-mark.webp`: resized/optimized from the project logo supplied directly by the repository owner. The original source image remains with its creator; it is not a derivative of the Claude/Codex marks.
