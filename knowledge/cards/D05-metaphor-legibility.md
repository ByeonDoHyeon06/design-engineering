# D05 — Test competing visual metaphors at use size

**Type:** PRACTITIONER  — **Documented perspective:** kare  — **Source ID:** PM5

## Useful problem signal
Different symbols may encode the same function with different recognition costs.

## Portable design move
1. List plausible metaphors for the same meaning.
2. Sketch simple candidates.
3. Test at real scale with people unfamiliar with the design.

## Provenance boundary
Do not prescribe pixel art or reuse recognizable historical iconography; source is an interview.

Check `methods/designer-methods.json` and `knowledge/sources.json` for institutional/primary URLs and the actual access level. This is a perspective to question, **not** a persona to emulate or an aesthetic to reproduce.
