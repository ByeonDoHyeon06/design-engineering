# P04 — Design for actual intent, not interface labels

**Type:** METHOD  — **Source IDs:** S2, S3, H1

## Use when
A requested interface contains multiple actions, user expertise levels or consequences.

## Evidence and scope
ISO human-centered design supplies general process requirements; specific visual solutions remain contextual. Refer to `knowledge/sources.json` for original source URLs and access limits.

## Transferable reasoning moves
1. Describe what must be understood, decided, created, monitored or recovered.
2. Mark sensitive/reversible/irreversible actions and task frequency.
3. Choose exploration and validation suited to those goals without mapping category names to visual presets.
4. Check novice and expert paths only if the product needs both.

## Do not infer
- No universal density, card, grid or color for any named category.
- Do not infer user research you did not conduct.

## Verify the output
Run representative tasks (finding, deciding, acting, undoing) under relevant device and stress conditions.
