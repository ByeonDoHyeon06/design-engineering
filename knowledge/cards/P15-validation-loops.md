# P15 — Prototype and inspect in the actual medium

**Type:** METHOD  — **Source IDs:** DC2, S2, H1

## Use when
Source code looks plausible but visual/interaction reality is uncertain.

## Evidence and scope
Iterative prototyping is a design process; tooling captures only part of the outcome. Refer to `knowledge/sources.json` for original source URLs and access limits.

## Transferable reasoning moves
1. Make the smallest inspectable artifact that tests a design hypothesis.
2. View desktop/mobile renders under controlled conditions, checking typography, clipping, contrast, alignment and visual hierarchy.
3. Execute keyboard flows, anchor landings, filters, forms, error and recovery states where in scope.
4. Fix the observed artifact then rerun relevant checks.

## Do not infer
- Do not report screenshot checks as user testing or screen-reader certification.
- Avoid optimizing arbitrary LLM aesthetic scores by adding decoration.

## Verify the output
Keep explicit evidence notes of observed issues and follow-up verification.
