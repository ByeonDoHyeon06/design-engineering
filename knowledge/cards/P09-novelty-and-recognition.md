# P09 — Balance new expression with recognizable meaning

**Type:** RESEARCH  — **Source IDs:** E4, A7, A14, CR2

## Use when
A design brief wants distinctive identity without sacrificing comprehension.

## Evidence and scope
Complexity and prototypicality influence first impressions in tested web stimuli; context and population matter. Refer to `knowledge/sources.json` for original source URLs and access limits.

## Transferable reasoning moves
1. Identify which elements should be familiar for task recognition and which may be distinctive.
2. Try novelty in the visual message or relationship, not in every control behavior.
3. Compare the most distinctive choice against a more conventional alternative.
4. Validate the tradeoff with the target user and brand meaning.

## Do not infer
- Prototype preference experiments are not conversion guarantees.
- A14 is a newer record retained with prior-verification status; verify the original before relying on exact claims.

## Verify the output
